# Holiday Gift Planner

A desktop application planned for SDEV 265 by The Computer Scientists.

## Project Overview

The Holiday Gift Planner will help users organize recipients, gift ideas,
prices, and a holiday shopping budget in one place.

The application will use Python and Tkinter, with gift information saved
locally for future shopping sessions.

## Planned Features

- Add and view gift recipients.
- Add and view gift ideas and prices for each recipient.
- Set a budget and calculate planned spending and remaining funds.
- Mark gifts as purchased.
- Save and reopen a gift list.

Editing, deleting, user accounts, shared lists, online shopping, and
reminders are outside the scope of the first version.

## Technology

- Python 3
- Tkinter
- Local file storage, with JSON under consideration
